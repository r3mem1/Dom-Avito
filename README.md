# Dom Avito

Prototype cliquable d'une place de marché de petites annonces pour la République du Congo (Brazzaville, Pointe-Noire). Nom de travail de l'interface : **Tekisa**.

Un seul fichier `index.html`, sans dépendances : ouvrez-le dans un navigateur.

- Interface en français, avec lingala et kituba partiels
- Prix en FCFA, contact par WhatsApp, MTN MoMo / Airtel Money (simulés)
- Données de test, état en mémoire, code SMS de démonstration : `1234`
